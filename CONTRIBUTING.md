# Contributing

Contributions are welcome for adversarial synthetic examples, deterministic heuristics, documentation and accessibility.

1. Open an issue with an invented dataset and clear expected/actual results.
2. Implement one focused change with a failing-then-passing negative test.
3. Run npm test, npm run check:site, and npm run demo.
4. Submit a PR with scope, evidence and possible false positives.

Do not submit actual datasets, secrets, customer records, credentials, personal data, trading systems, paid services or unlicensed client/employer material. Keep examples source-only and offline.
